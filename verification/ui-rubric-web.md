# UI Self-Review Rubric — Web (File 02 §7, lean pass mark ≥ 80 %)

Reviewed by the build agent against the 10 committed screenshots in
`verification/screenshots/web/` (5 pages × 390 px / 1440 px), generated by the Playwright
screenshot spec against the production-served build with seeded demo data. The dedicated
visual-judge subagent was unavailable (provider error), so the review was performed by
direct screenshot inspection per File 01 §F visual-gate fallback.

Two defects were found by this review and fixed before scoring:

1. **Generated spacing tokens collided with Tailwind's default scale** (`8` = 8 px vs
   Tailwind's 32 px) — visibly squashed the onboarding PIN pad (`h-12`, `w-8`). Fixed by not
   extending `spacing` (the default scale already is the 4-pt grid) — re-shot.
2. **Charts dropped sparse data**: index-modulo sampling skipped the only non-null buckets
   and x-positions were index-scaled instead of time-scaled. Rewritten time-proportional
   with dot markers — re-shot.
